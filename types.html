CHAPTER 02 · LEARNING METHODS

Types of Machine Learning

Not every machine learns in the same way. Explore three major learning approaches and discover how they solve different problems.

01 / LEARN WITH ANSWERS

🎓

Supervised Learning

The model learns from labeled data. Each training example contains input data and its correct answer.

Visual example

Real-world example

Predicting house prices using past house prices, sizes, and locations.

Regression · Classification

02 / DISCOVER PATTERNS

🔍

Unsupervised Learning

The model learns from unlabeled data. It discovers hidden patterns or groups without being given the correct answers.

Visual example

Real-world example

Grouping customers according to their shopping habits.

Clustering · Pattern Discovery

03 / LEARN THROUGH FEEDBACK

🎮

Reinforcement Learning

An agent learns by taking actions and receiving rewards or penalties from its environment.

Visual example

Real-world example

Training a game-playing agent to choose actions that increase its score.

Agent · Actions · Rewards
